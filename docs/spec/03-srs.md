# §3. Интервальные повторения

Раздел `docs/SPEC.md`. Оглавление — [SPEC.md](../SPEC.md).

---

Библиотека `fsrs` (py-fsrs). Свой алгоритм не писать.

`vocab_cards`: `id, course_id, term, translation, context, source, fsrs_state (JSON), due_at`.

Три источника карточек:
1. Материал узла — при прохождении темы.
2. Отмеченное пользователем при чтении и просмотре.
3. **Собственные ошибки** из проверенных работ.

Третий источник — ключевой обучающий контур: ошибся → получил карточку → повторил. Не побочный эффект, а причина, по которой подсистема существует.

Лимиты дневной колоды (сколько новых, потолок всего) задаются курсом. Карточка двусторонняя. Контекст обязателен — единица без контекста бесполезна.
