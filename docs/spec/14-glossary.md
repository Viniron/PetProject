# §14. Глоссарий

Раздел `docs/SPEC.md`. Оглавление — [SPEC.md](../SPEC.md).

---

**Пара** — учебное занятие в университете. **ИСУ / ITMO ID** — аккаунт ИТМО, вход в my.itmo.ru. **Сессия** — один слот занятия внутри курса (не экзаменационная). **Активность** — блок внутри сессии. **Узел (node)** — элемент змейки. **SRS / FSRS** — интервальные повторения. **Rollover** — перенос незавершённого узла на следующий рабочий день курса. **external_key** — идентификатор события в Google Calendar. **day_flags** — периоды, исключённые из учёбы и из расчёта отставания.
