# §7. Подбор материалов

Раздел `docs/SPEC.md`. Оглавление — [SPEC.md](../SPEC.md).

---

Утренний джоб, до начала учебного дня:

1. Голова очереди → тема дня.
2. Найти материал по тегам узла: приоритет внешним источникам.
3. **Валидация ссылки:** доступность, тип, длительность в допустимом диапазоне, наличие требуемых курсом атрибутов.
4. Отдельно — материал для активностей вне сессии, если курс их объявляет.
5. Проверка по `content_history`: повторно не рекомендуем.
6. Генерация упражнений по теме.
7. Внешнего материала нет → объяснение от модели, **в UI помечено как объяснение ассистента**, а не выдаётся за внешний источник.

`content_items`: `url, kind, title, duration, tags[], attrs (JSON), source, http_status, checked_at`. Кэш переиспользуется между днями и курсами. Политику подбора (какие источники, какие атрибуты обязательны, что чередовать) задаёт манифест курса.

**Только легальные источники.** Ссылки на пиратские ресурсы не выдаём ни при каких настройках курса.
