# SPEC.md — оглавление спецификации

Дополняет `CLAUDE.md`. Описывает **приложение**, а не учебные программы.
Текст разделов — в `docs/spec/`, по файлу на раздел: открывать нужный,
а не читать спецификацию целиком. Ссылка вида «`SPEC.md` §11.2» ведёт сюда,
отсюда один шаг до файла.

**Границы документа.** Здесь нет и не должно быть: содержания курсов, тем,
уровней, пропорций занятия, лимитов повторений, названий конкретных моделей
и их цен. Всё это приходит от owner — программы отдельными файлами курсов,
выбор моделей отдельным решением. Задача платформы — исполнить **любую**
программу и обратиться к **любой** назначенной модели. Пункты с **[?]**
требуют подтверждения owner.
