# ADR-008 · Мультипровайдерная маршрутизация моделей

Запись журнала решений. Указатель — [DECISIONS.md](../DECISIONS.md).

---

**2026-08-13 · принято · заменяет ADR-007**

ADR-007 ограничивал выбор моделями Anthropic. Отменено: при равном качестве это переплата. Маршрутизация теперь по всем доступным провайдерам, критерий — планка качества за меньшую цену.

**Целевая конфигурация: Google на всю текстовую работу + Azure на весь голосовой слой.** Anthropic остаётся в `llm.routing` как резерв для проверки письма. Провайдеров не больше двух-трёх: каждый — отдельный аккаунт, оплата, лимит и режим отказа, и экономия центов не оправдывает эту нагрузку.

| Задача | Модель | $/1M |
|---|---|---|
| Закрытые задания | без модели | 0 |
| Карточки, извлечение событий | GPT-5.6 Luna | 0.20 / 1.20 |
| Упражнения, материалы, диалог | Gemini 3.6 Flash (+Batch) | 1.50 / 7.50 |
| Проверка письма, оценка речи | Gemini 3.1 Pro | 2 / 12 |
| Vision (фото → событие) | Gemini 3.1 Flash-Lite | 0.25 / 1.50 |
| STT + произношение + TTS | Azure AI Speech | ~$1/час |

*Почему не Anthropic по умолчанию на проверке письма:* Gemini 3.1 Pro вдвое дешевле Opus 5 на выходе, и у Opus 5 есть надбавка токенизатора (~30% больше токенов на том же тексте, модели 4.7+), из-за которой фактический разрыв ещё больше. Качество на этой конкретной задаче публичными бенчмарками не измеряется — решает локальный замер (SPEC §7.4). Если замер покажет преимущество Opus 5 или GPT-5.6 Sol по стабильности оценок, решение пересматривается: разница в несколько долларов в месяц не стоит недостоверных баллов.

*Почему не общий лидерборд как критерий:* индекс Artificial Analysis взвешен как агенты 34% / кодинг 24% / научное рассуждение 24% / общее 18%. Для проверки эссе и разговорной практики релевантны только IFBench (надёжность формата вывода) и Multilingual Index. Место в общем зачёте здесь ничего не предсказывает.

*Отклонено:* DeepSeek V4 Flash как основной дешёвый уровень — данные уходят в китайскую юрисдикцию, и сообщалось о наценке в часы пик, что ломает предсказуемость бюджета. Допустим только для неличных данных (генерация карточек), если замер покажет выгоду.

*Бюджет:* ~$9–11/мес, из которых ~$6–7 это голосовой слой. **Доминирует голос, а не токены** — оптимизировать в первую очередь его.
