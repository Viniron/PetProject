# ADR-009 · Оценка произношения через Azure AI Speech

Запись журнала решений. Указатель — [DECISIONS.md](../DECISIONS.md).

---

**2026-08-13 · принято предварительно, требует валидации**

Четвёртый критерий IELTS Speaking (Pronunciation) закрывается Azure AI Speech Pronunciation Assessment: оценки на уровне фонем, слогов, слов и полного текста плюс fluency, completeness и prosody, по ставке обычного speech-to-text.

*Почему это меняет прежнее решение:* в ADR по разговорной практике произношение было записано как принципиально неоцениваемое, потому что модель, получающая расшифровку, звук не слышит. Azure оценивает сам звук, до всякой LLM. Транскрипт и оценка приходят в одном вызове, то есть отдельный STT-провайдер не нужен.

*Обязательная валидация до внедрения:* прогнать 20–30 своих записей и проверить, что фонемные оценки указывают на конкретную проблемную фонему, а не занижают все фонемы слова разом (есть сообщения разработчиков о таком поведении). Prosody доступна только для локали en-US.

*Если валидация провалится:* фолбэк — честно оставить критерий незакрытым в приложении и отдать его живому преподавателю перед экзаменом. Поле под pronunciation в `speaking_results` завести в любом случае.
