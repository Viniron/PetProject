# apps/web — интерфейс

Next.js со **статическим экспортом**: на плате раздаётся готовая статика,
Node в рантайме нет (ADR-020). Рендерить на сервере нечего — источник истины
backend (инвариант 1).

## Команды

Все из корня репозитория, `make help` — список целиком.

```bash
make web-install   # npm ci: ровно то, что в package-lock.json
make web-dev       # :3000, /api проксируется на 127.0.0.1:8000
make web-build     # экспорт в apps/web/out
make web-lint      # eslint + tsc --noEmit
make web-test      # vitest
make web-client    # перегенерировать src/api/schema.d.ts из контракта
```

`make web-dev` без `make dev` рядом покажет интерфейс без данных: запросы
к API упрутся в закрытый порт.

## Три вещи, которые легко сломать

**Вкладки генерируются из списка курсов** (инвариант 3). Хардкод списка —
баг: он ломает установку и удаление курсов. Курсов сегодня ноль, и капсула
с одной вкладкой — настоящее состояние, а не заглушка
(`src/courses/installed.ts`).

**Клиент генерируется из контракта.** `src/api/schema.d.ts` — результат
`make web-client`, править руками нечего. Расхождение файла с
`packages/contracts/openapi.json` роняет `tests/contract.test.ts`, то есть
обычный `make web-test`.

**Палитра берётся из `design/tokens.css` напрямую,** без копии внутри
`apps/web`: копия разъезжается с оригиналом молча, и первым это видит owner
на экране. Импорт выходит за пределы каталога приложения, поэтому
`next.config.ts` объявляет корнем сборки корень репозитория.

## Что где лежит

```
src/app/        маршруты (App Router), globals.css, телефонная раскладка
src/shell/      оболочка §8.1: капсула, вкладки, контекстное действие
src/api/        клиент: schema.d.ts (генерируется) и обёртка над fetch
src/courses/    список установленных курсов
tests/          vitest; jsdom просит только файл с разметкой
```

Макеты, по которым делается интерфейс, — `design/mockups/`, состояние
дорожки дизайна — `design/PROGRESS.md`. Компоненты оболочки (`app`, `rail`,
`tab`, `rail-action`, `content`) живут в `design/tokens.css`: значение,
прописанное мимо токенов, ломает системность стиля.
