# Контракт API

`openapi.json` — схема OpenAPI живого приложения `apps/api`. **Источник
истины для клиентов:** фронт Э7 генерируется из этого файла, а не пишет
запросы руками.

## Почему файл коммитится

Генерируйся он при сборке фронта — изменение контракта было бы невидимо.
Здесь оно приходит диффом в пул-реквест: исчезнувшее поле или новый код
ответа замечает ревью, а не экран owner.

## Как обновлять

```bash
make contract        # перезаписать файл из app.openapi()
make test            # сверка живёт в apps/api/tests/test_contract.py
```

Перегенерация — ручной шаг, и это не забывчивость, а требование: файл
коммитится **вместе** с правкой эндпоинтов, одним коммитом.

`make test` краснеет в двух случаях, и оба — настоящие изменения контракта:

1. Эндпоинты поправлены, `make contract` не запущен.
2. Эндпоинты не менялись, но поднялась версия FastAPI — от неё меняется
   генерируемый клиент, значит это тоже правка контракта.

## Что в нём есть и чего нет

Э6 отдаёт сетку календаря и периоды исключений `day_flags`. Захвата
событий нет — он принадлежит Э8; аутентификации и CORS нет — они отложены
до Э7 (ADR-031), пока сервис слушает только `127.0.0.1`.

Занятий курсов (`study`) в контракте нет и появиться они не могут молча:
это закреплено тестом. Их время считается по манифесту курса (SPEC §4),
который уехал в дорожку курсов вместе с ADR-027 п. 11.

## Имена

Имена схем и ключи полей — латиницей и `snake_case`, как колонки базы,
хотя код проекта русский: из имён схем генератор делает имена типов
TypeScript. Значения строк при этом русские — причина периода это то,
что owner напечатал.
